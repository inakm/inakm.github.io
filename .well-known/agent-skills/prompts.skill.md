# AI Prompts Hub

Access a curated collection of AI prompts for finance, analysis, and productivity.

## Endpoints

### Browse Prompts
```
GET /page/prompts/
```

Returns an index of all available prompt categories.

### View Prompt
```
GET /page/prompts/{category}/index.html
```

Returns prompts in a specific category.

## Usage

Each prompt is formatted with instructions, context, and expected output format.
Agents can use these prompts to guide their responses in finance-related tasks.
